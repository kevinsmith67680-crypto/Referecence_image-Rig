# Phase 3.8.1: Phase 0 native Moho readiness check

**Status: NOT EXECUTED.** Moho cannot run in this cloud environment: it is a macOS application, and the sandbox is
Linux without Moho. Nothing in this document claims native behaviour. What was checked here is listed in §1; what
the smallest native test needs from the user's Mac is in §2.

Phase 4 (the full native exporter) was **not** started.

> **Later (Phase 4.0):** a smaller, self-checking native proof on the character's own artwork replaces the procedure below as the first native step. It runs through `tools/macos/phase4_native_test.sh`; see [`phase4_completion_report.md`](phase4_completion_report.md).

## 2. The smallest native test (about 10 minutes on the Mac)

It covers exactly what this phase asked for: a bone layer, imported artwork, one movable arm, save, reopen, move the
arm. It reuses the Phase 0 tooling; nothing new has to be installed.

Prerequisites: Moho Pro 14 (or 14.5) on the M1 Mac, this repository checked out (paths may contain spaces), Python
3.12 with the repository's virtual environment.

```bash
tools/macos/install_phase0.sh --custom-content "<Moho Custom Content Folder>"
```

The installer generates `build/moho/AutoRig_Phase0_Build.lua` with this checkout's absolute paths and copies it into
`<Custom Content Folder>/Scripts/Menu/AutoRig/`. It never touches the Moho application bundle.

| step | in Moho | expected | result |
|---|---|---|---|
| 1 | Restart Moho; File > New (1920×1080) | empty document | |
| 2 | Scripts > AutoRig > AutoRig Phase 0: Build Test Rig | alert "test rig built"; no `ERROR` in the Lua console | |
| 3 | Layers panel | bone layer `AutoRig_Phase0` holding `forearm_art`, `upper_arm_art`, `head_art`, `torso_art` | |
| 4 | Select `upper_arm_art`; check its bound bone | bound to `upper_arm` | |
| 5 | Frame 0, Manipulate Bones: rotate `upper_arm` about 30° | the upper arm **and** the forearm art turn about the shoulder; torso and head stay | |
| 6 | Cmd+Z, then File > Save As `phase0_smoke.moho` (any folder, SSD path with spaces is fine) | file written | |
| 7 | Close the document, File > Open `phase0_smoke.moho` | same layers, bones and bindings; the art loads (no missing-image warnings) | |
| 8 | Frame 0, rotate `upper_arm` again | same behaviour as step 5 | |
| 9 | Back in the terminal: `python -m autorig verify-report examples/phase0_test_character/rig_spec.json examples/phase0_test_character/phase0_moho_report.json` | `VERDICT: PASS` | |
| 10 | Optional: `python -m autorig moho-file inspect phase0_smoke.moho` | lists the bone layer, 4 bones and 4 image layers (reads the saved file; no Moho needed) | |

Send back the report JSON, the console output, a screenshot after steps 5 and 8, and `phase0_smoke.moho`. A PASS
on steps 1–9 raises the Phase 0 native status from NOT EXECUTED to PASS for these capabilities, and only for them.
The full checklist (`docs/phase0/manual-verification.md`, A–F) remains the gate for Phase 4.
